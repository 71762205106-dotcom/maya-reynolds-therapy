# Dr. Maya Reynolds Therapy Website

Responsive therapy website for Dr. Maya Reynolds, PsyD, built with Next.js and Tailwind CSS.

## Features
- Responsive desktop and mobile design
- About and client-focused sections
- Three therapy services
- How We Work section
- Custom Our Office section using provided office photography
- FAQ accordion
- Contact call-to-action
- SEO metadata

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.
